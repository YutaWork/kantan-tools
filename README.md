# かんたんツール集

登録・ログイン不要で使える、無料のウェブツール集です。
すべての計算と処理はブラウザの中で行われ、入力した内容が外部に送信されたり保存されたりすることはありません。

## 収録ツール

- 文字数カウンター
- パスワード生成
- 単位変換
- 消費税・割り勘計算
- ローン計算（概算）
- 積立シミュレーション（概算）
- タイマー＆ストップウォッチ
- 日付計算
- 割引・パーセント計算
- 時間の計算
- 年齢計算
- 電卓
- ポモドーロタイマー
- 年収・時給換算（概算）
- 燃費・ガソリン代計算
- ルーレット・抽選
- 進数変換

## 技術

HTML / CSS / JavaScript のみの静的サイトです。バックエンド、データベース、APIは使用していません。
