# かんたんツール集

登録・ログイン不要で使える、無料のウェブツール集です。現在は7分野・44ツールを収録しています（2026年11月22日の再編成時点）。
すべての計算と処理はブラウザの中で行われ、入力した内容が外部に送信されたり保存されたりすることはありません。

## 収録ツール

- 文字数カウンター
- パスワード生成
- 単位変換
- 消費税・割り勘計算
- ローン計算（概算）
- 積立シミュレーション（概算）
- タイマー＆ストップウォッチ
- 日付計算
- 割引・パーセント計算
- 時間の計算
- 年齢計算
- 電卓
- ポモドーロタイマー
- 年収・時給換算（概算）
- 燃費・ガソリン代計算
- ルーレット・抽選
- 進数変換
- 平均・合計計算
